Make a bootable USB stick

Write the AIRUX ISO to a USB stick, then start your PC from it. You can try AIRUX without changing anything on your computer, and install it only if you want to.

Everything on the USB stick is erased. Use a stick of 8 GB or more with nothing on it you need.

1. Write the ISO to the stick

Pick your computer's system. Don't have the ISO yet? Download it first.

Windows

With Rufus (recommended)

  1. Download Rufus from its official site and open it.
  2. Under Device, choose your USB stick. Under Boot selection, choose $iso_file.
  3. Click Start. When Rufus asks how to write the image, choose Write in DD Image mode. (ISO mode does not boot this image reliably.)
  4. Wait until the status says Ready, then close Rufus.

Or with balenaEtcher

  1. Download balenaEtcher from its official site.
  2. Flash from file → choose the ISO → Select target → your stick → Flash!

macOS

  1. Download balenaEtcher from its official site.
  2. Flash from file → choose $iso_file → Select target → your stick → Flash!
  3. If macOS says the disk is not readable afterwards, click Eject: that is expected.

AIRUX runs on 64-bit Intel and AMD PCs. It does not run on Apple Silicon Macs.

Linux

  1. Find the stick with lsblk. Here it is /dev/sdX: make sure it is the stick, not your disk.
  2. Write the ISO: 
    sudo dd if=$iso_file of=/dev/sdX bs=4M status=progress conv=fsync
  3. When the command finishes, the stick is ready.

balenaEtcher also works on Linux.

2. Start your PC from the stick

  1. Plug in the stick, then turn the PC on while pressing its boot-menu key:
    BrandBoot-menu key
    AcerF12 (turn it on first: press F2 at power-on, open Main, set F12 Boot Menu to Enabled)
    DellF12
    HPF9
    LenovoF12
    ASUSEsc
  2. Choose the USB stick (the UEFI entry). Secure Boot can stay on.
  3. The AIRUX menu starts the live system after 5 seconds. The desktop opens without a password.
  4. AIRA's models take 1–3 minutes to load from the stick. When her status shows idle, she is ready.

3. Try AIRA

  • Click Talk or press Ctrl+Space, speak, then press it again. Typing works too.
  • Try "How much disk space do I have?" or "Remind me in two minutes to stretch".
  • Anything risky (deleting, installing, sending something off the PC) waits under Waiting for you until you confirm.

4. Install AIRUX (optional)

The installer's "Erase disk" option wipes the whole disk, including Windows. On a computer you want to keep as it is, use the live system only, or install on a spare disk.
  1. Double-click Install AIRUX on the desktop.
  2. Choose language, location and keyboard, then the disk: Erase disk, or Manual for a spare partition.
  3. Set your name, user name, computer name and password, then Install.
  4. Restart and remove the stick. At first boot AIRUX measures your hardware and picks AIRA's model size.

If something goes wrong

ProblemWhat to do
The stick is not in the boot menuWrite it again in DD Image mode. To test, turn off Secure Boot.
Black screen after the menuAt the AIRUX menu press e, add nomodeset to the line that starts with linux, then press F10.
AIRA says she can't reach the modelWait a minute: the model is still loading from the stick.
No sound or microphonePick the output or input device under the volume icon in the taskbar.
